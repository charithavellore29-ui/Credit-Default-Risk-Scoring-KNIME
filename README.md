
# Credit Default Risk Scoring & Customer Segmentation

## Project Overview
A data analytics project developed using KNIME Analytics to explore credit default risk and customer segmentation.

## Tool Used
- KNIME Analytics Platform

## Project Focus
- Credit default risk analysis
- Customer segmentation
- Data analytics workflow

## Project Objective
To explore credit risk patterns and customer segments through a structured analytics workflow using KNIME.
